Under The Hood

Built for Engineers Who Care About Privacy

Weave does not relay your chats or source code to third-party cloud servers. Everything executes on your workstation.

terminal

Dual Execution Mode

Run through your local Google Antigravity (agy) CLI with persistent project context, or connect directly to Google AI Studio with your Gemini API key.

AGY_BIN=agy / GEMINI_API_KEY
key

Google OAuth 2.0 (PKCE)

Connect your Google account with zero server secrets using standard loopback PKCE. Safely read and draft Gmail messages, schedule Google Calendar events, and access Gemini models.

npm run auth (Port 8085)
lock

Workspace Isolation

Bind WhatsApp groups to specific project directories with /bind <path>. Senders in team chats can never touch unauthorized directories on your hard drive.

Directory sandbox jail
screenshot_monitor

Headless Visual QA

Ask for visual verification on any mobile or desktop screen. Weave spins up headless Firefox, renders the local dev server, and replies directly to WhatsApp with the screenshot.

/screenshot [desktop|mobile]
mic

Voice Note Speech-to-Code

Walking or commuting? Send a WhatsApp voice memo. Weave transcribes the audio via Groq Whisper or local engine and forwards the extracted instructions straight to Gemini.

GROQ_API_KEY / Whisper STT
calendar_month

Calendar Invites & SMTP

Schedule meetings with natural language. Weave creates calendar events directly via Google Calendar API or generates RFC 5545 compliant .ics files attached to WhatsApp messages.

Direct Google Calendar API
3-Step Setup

Up and Running in 60 Seconds

Clone the repo, pair your WhatsApp session via QR code, and prompt your agent.

1

Install Dependencies

Ensure Node.js 18+ is installed on your Linux or macOS machine:

git clone https://github.com/darthnihilius01/weave.git && cd weave && npm install
2

Connect Google Services (Optional PKCE)

Authorize your Google account for Gemini API, Calendar & Gmail access without any secret keys:

npm run auth
3

Launch the Bridge & Scan QR

Start the daemon. Scan the QR code with WhatsApp (Linked Devices → Link a Device):

npm start

You're ready. Message @agent Hello! in any solo chat or group.

Architecture

How Weave Works.

A four-layer pipeline turning asynchronous mobile WhatsApp messages into verified local commits and visual diffs.

SYSTEM: LOCAL LOOPBACK DAEMON
LAYER 1 Socket Ingestion

WhatsApp Multi-Device Socket

Baileys links directly to your WhatsApp account as an authorized companion device. Captures text, voice memos, and attachments with zero third-party brokers.

baileys / e2e-crypto
LAYER 2 Access & Security

Group Binding & Isolation

Sandboxes commands to authorized project folders using /bind <path>. Whitelists phone numbers and blocks arbitrary directory traversal.

chroot / path-jail
LAYER 3 AI Execution

Antigravity & Gemini Engine

Spawns Google Antigravity (agy) CLI subprocesses or dispatches REST requests with Gemini 3.8 Flash. Reads code, generates diffs, and runs builds.

agy binary / gemini-3.8
LAYER 4 Verification

Headless QA & Media Dispatch

Launches headless Firefox, captures viewport snapshots (desktop & mobile 375x812), and sends compressed media and git commit hashes directly back to the chat.

headless-firefox / wa-media
